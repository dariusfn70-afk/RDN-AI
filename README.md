# RDN AI

RDN AI is a simple ChatGPT-style web app powered by the Gemini API.

## Local setup

1. Install Node.js 18+.
2. Run `npm install`.
3. Create a `.env` file from `.env.example`.
4. Put your Gemini API key in `GEMINI_API_KEY`.
5. Run `npm start`.
6. Open `http://localhost:3000`.

## Render

Set this Environment Variable:

- `GEMINI_API_KEY` = your Gemini API key

Optional:

- `GEMINI_MODEL` = `gemini-3.5-flash-lite`

The free Gemini API tier has usage limits. Never put your API key in GitHub or frontend JavaScript.
